https://data.gov.sg/datasets?query=dengue&resultId=d_dbfabf16158d1b0e1c420627c0819168
NEA Dengue Clusters (GEOJSON) - snapshot of currently active clusters only (locality, CASE_SIZE, breeding habitats). Not a time series. Dataset id d_dbfabf16158d1b0e1c420627c0819168. Useful later for spatial work if snapshots are collected over time.

https://data.gov.sg/datasets/d_ca168b2cb763640d72c4600a68f9909e/view
MOH Weekly Infectious Disease Bulletin Cases - Jan 2012 to Dec 2022, columns epi week / disease / no. of cases. Includes Dengue Fever and DHF. MAIN target source.

https://data.gov.sg/datasets/d_ac1eecf0886ff0bceefbc51556247015/view
MOH Weekly Number of Dengue and DHF Cases - 2014 to 2018. Use to cross-check the bulletin.

https://data.gov.sg/dataset/dengue-cases
NEA Dengue Cases collection (regional GEOJSON: Central, North East, North West, South East, South West). Last 14 days only, snapshot.

https://data.gov.sg/dataset/historical-daily-weather
NEA Historical Daily Weather Records 2009 - Nov 2017 (rainfall, temperature, wind). id d_03bb2eb67ad645d0188342fa74ad7066

https://data.gov.sg/datasets/d_e3b1111a26b2aefef4f386c068d4ca5d/view
NEA Relative Humidity Monthly Mean, Changi, 1982 - present.

https://data.gov.sg/datasets/d_7916c4c0cbe0dfaadaeac4b56d732a2a/view
NEA Historical Relative Humidity across Singapore (per year datasets, station-level, high frequency, no QC).

https://archive-api.open-meteo.com/v1/archive
Open-Meteo historical weather API, free, no key. Daily rainfall, temperature, humidity for any lat/lon, 1940 - present. Used as main weather source (lat 1.3521, lon 103.8198).

https://api-open.data.gov.sg/v2/real-time/api/rainfall
data.gov.sg real-time weather API (rainfall, air-temperature, relative-humidity) per station, can query by date. Option for station-level weather later.

https://opendengue.org
OpenDengue - global dengue case database (Clarke et al. 2024, Scientific Data). Has Singapore national data, useful for extending/validating the series.

https://www.nea.gov.sg/dengue-zika/dengue/dengue-cases
NEA weekly dengue case figures - for 2023 onward (not on data.gov.sg API). May need manual collection / scraping.

https://www.cda.gov.sg  (Communicable Diseases Agency, took over weekly bulletins) - check for weekly infectious disease bulletin 2023+.

https://pmc.ncbi.nlm.nih.gov/articles/PMC9451123
Dataset paper: weekly dengue clusters in Singapore Feb-Jul 2020 mapped to subzones (Scientific Data 2022). Possible spatial extension.

Subzone boundaries - for mapping clusters to areas if going spatial.
