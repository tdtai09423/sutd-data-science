\section{Reproducibility and contributions}
\label{sec:reproducibility}
Code, configuration, processed weekly snapshots, figures and data provenance are provided with
this report. The main analysis is reproduced with \texttt{cd pipeline \&\& python run.py all}
(about 9 hours with weekly refits); \texttt{python run.py evaluate} re-scores the saved
out-of-sample predictions in minutes. The 2014--2018 analysis uses
\texttt{--config config\_brief.yaml}. Random seeds are fixed. Raw files are downloaded by the
pipeline rather than redistributed; retrieval dates, hashes and licences are recorded in
\texttt{pipeline/data/raw/MANIFEST.json}, and the data dictionary is in \texttt{docs/DATA.md}.
