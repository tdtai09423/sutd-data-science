\section{Conclusion}
\label{sec:conclusion}
A transparent persistence rule already flags most next-week level surges in Singapore, and
lagged weather does not improve on recent counts. Statistical learning adds value mainly for
growth and onset surges, where count regression on log cases beats the baselines, but these
gains rest on few events and wide intervals. A useful next step is prospective evaluation with
post-2022 counts, spatial cluster data and serotype information.
